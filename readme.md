# sepsis_third_wave_demo —— 重症 AI 第三波浪潮仿真 DEMO

> ⚠️【学术仿真原型说明】本 Demo 仅模拟界面与算法逻辑，不实现真实临床管控。**所有输出仅作科研演示，不构成任何诊疗建议。**

核心思想来源：《Intensive Care Medicine》2026 述评（Elbers、Ercole、Angus）——**第三波浪潮：把在线强化学习与床旁自适应随机化嵌进临床工作流**：

- 模型**有把握时**（不确定性 < 阈值）→ 直接输出仿真最优方案参考；
- 模型**没把握时**（不确定性 > 阈值）→ 在人工维护的临床均势选项池内**自适应随机**分配；
- 观察结局 → 回传更新贝叶斯后验 → **照护本身成为持续学习的系统**（随机化被保留，仍然因果严谨）。

决策仿真点：脓毒症休克初始复苏完成后，**优先补液扩容 VS 上调去甲肾上腺素剂量**。

## 一、运行环境

- Python 3.12（PyCharm 2026 可直接打开本项目）
- 禁止 Docker / WSL / 虚拟机 / 外部数据库；持久化全部为本地 JSON / JSONL 文件

## 二、安装与启动

```bash
pip install -r requirements.txt
python main.py
```

浏览器访问：http://127.0.0.1:8000/static/index.html（或 http://127.0.0.1:8000/）

- 无需任何模型即可完整跑通全部 MAB 仿真功能；
- 前端 Tailwind CSS 与 Chart.js 走 CDN，需要联网加载一次。

## 三、🧩 可选功能：本地 LM-Studio 模型增强（不开启则完全不需要）

1. 启动 LM-Studio，开启 OpenAI 兼容 API（端口 1234）；
2. 同时加载：
   - LLM：`Qwen3-8B-GGUF` 或 `Qwen3.5-9B-GGUF`（模型 id：`qwen3-8b` / `qwen/qwen3.5-9b`）
   - Embedding：`nomic-embed-text-v1.5-Q8_0-GGUF`（模型 id：`nomic-ai/text-embedding-nomic-embed-text-v1.5`）
3. DEMO 首页勾选【启用本地大模型 & 向量检索增强】，页面会自动探测连接状态；
4. **硬隔离原则**：MAB 决策逻辑 100% 由 numpy 独立计算；LLM 仅对结果做自然语言解读，向量检索仅输出参考证据，二者**绝不干预、不修改 MAB 的决策输出**；
5. LM-Studio 未启动 / 模型未加载时，页面友好提示，**不崩溃**，原有 MAB 功能不受影响。

## 四、演示操作流程

1. `python main.py`，浏览器打开页面；
2.  可选是否勾选启用本地模型增强；
3. 选择「自动生成模拟患者轨迹模式」（或回放内置 10 例 CSV 病例），点击开始会话；
4. 【患者状态面板】点击"刷新下一时间步"，观察 MAP/乳酸/尿量/去甲肾上腺素/SOFA 趋势曲线与不确定性指数；
5. 【核心决策面板】调节不确定性阈值 → 执行决策计算 → 观察 🟢 高置信推荐 / 🟡 低置信随机两种分支；测试医生否决、安全闸门；开启模型增强后可调用 LLM 解读与向量检索证据；
6. 【结局反馈面板】填写仿真结局、调节奖励权重 → 提交 → 观察策略更新前后后验分布对比图；
7. 【审计日志】查看全链路记录，导出 JSONL。

## 七、算法说明

- **贝叶斯多臂老虎机（Thompson 采样）**：每臂收益 Bernoulli 假设，Beta(1,1) 均匀先验；每次决策从各臂后验抽样 θ，取 argmax；
- **不确定性分数（0-100）**：蒙特卡洛估计 P(最优臂)，`uncertainty = 100 × (1 − |2P − 1|)`——P=0.5（完全分不清）时为 100，P=1（确定）时为 0；
- **结局更新**：奖励 = 生存/乳酸改善/升压药减量三项加权（权重可调），`alpha += reward，beta += 1 − reward`；
- **不确定性定义与阈值构成两条分支**：`uncertainty < 阈值 → 推荐分支`；`uncertainty > 阈值 → 自适应随机分支`。

## 八、局限性文本

本 DEMO 仅实现第三波浪潮思想的离线仿真演示。原文设想的床旁在线自适应随机化完整系统还需要：伦理委员会审批、患者知情同意、临床专家组持续维护临床均势选项池、处理结局延迟反馈、统计 I 类错误控制、多模型冲突协调。因此，真实落地需要多学科协作，并非单纯算法工程可以完成。

【补充】本 DEMO 集成本地 Qwen 系列大模型与 nomic-embed-text-v1.5 向量检索仅作为演示增强；大模型仅对 MAB 仿真输出做自然语言解读，向量检索用于展示参考指南证据，**二者均不参与治疗决策计算**。真实临床使用 LLM 检索仍需要严格的质控与人工复核。本 DEMO 仅用于科研概念演示。
