🌊 第一波：任务专用机器学习

脓毒症风险预测、亚表型划分等。教训：预警增加了工作负荷，却没有改善结局——"算得出"不等于"可行动"。

🤖 第二波：生成式 Agent 大模型

我们 POC1-5 所处阶段：指南证据助手、多 Agent 会诊。现状：能力"超人"，但验证最少的应用反而最贴近患者。

🎯 第三波（本 DEMO）：在线自适应随机 + 照护即学习

模型有把握时直接推荐最优方案；没把握时在临床均势选项池内自适应随机，观察结局、持续更新策略。随机化被保留 → 仍然因果严谨。【仅仿真演示】
